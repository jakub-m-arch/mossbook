# Fonts embedded in PDF reports

`NotoSans-Regular.ttf` and `NotoSans-Bold.ttf` are Noto Sans by The Noto Project
Authors (https://github.com/notofonts/latin-greek-cyrillic), licensed under the SIL
Open Font License 1.1 (`OFL.txt`). Taken from the `@expo-google-fonts/noto-sans@0.4.2`
npm package. They cover Polish, Ukrainian and the rest of Latin and Cyrillic, and are
subset into each generated PDF.
